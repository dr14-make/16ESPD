Lecture 1 hands-on: build the car

From an empty Dyad library to the car the notebooks drive — 90 minutes in Dyad Studio

You build the longitudinal car of notebook 01 from standard-library parts, one component at a time, mostly in the diagram editor. At the end of step 5 your car reaches the same terminal speed as the course model Vehicle.CarPlant. Step 6 gives its wheel inertia. Steps 7–10 are for home or for anyone who finishes early: they need equations, and end with the car spinning its wheel on a slippery road.

Every component here exists in the course repository under dyad/HandsOn/, and every number in a checkpoint was read off a run of it. The budgets add up to 85 minutes, which leaves 5 minutes of slack in a 90-minute session.

Steps

  1. Tour: one model, two views — 10 min
  2. Engine — 20 min
  3. Driveline — 10 min
  4. Body — 15 min
  5. Car: full throttle to terminal speed — 20 min
  6. A wheel with inertia — 10 min
  7. A road with a gradient — take-home
  8. Tire friction against slip — take-home
  9. A wheel that can slip — take-home
  10. Standing start on a slippery road — take-home

Before class

Do this at home — it downloads a lot
  • Dyad Studio is installed in VS Code and you are signed in.
  • You have created a new, empty Dyad library (call it MyCar) with Dyad Studio's new-library command.
  • Pkg.instantiate() has finished in that library's environment. The first run downloads and precompiles the standard libraries, which can take a long time.
  • The library browser lists BlockComponents, RotationalComponents and TranslationalComponents, and you can expand them.

Names in this guide are the ones the reference models use. Keep them: the checkpoints name signals such as car.v_kmh, and a different instance name means a different signal name.

From dyad/HandsOn/Engine.dyad, copied verbatim except that each metadata { … } block — diagram layout and test cases — is left out. The {^…} tag at the end of a line points into that layout; the diagram editor writes it for you, and you can drop it if you type the code by hand. """
Torque command in, shaft torque out, through a transport delay, a first-order lag and a torque
ceiling.
"""
component Engine
  "Commanded torque"
  tau_cmd = RealInput() {^tau_cmd}
  "Output shaft"
  spline = Spline() {^spline}
  "Engine mounts"
  support = Spline() {^support}
  # m = n - 1 leaves the delay without direct feedthrough, so a command step cannot leak through
  # the limiter before the delay has elapsed.
  delay = BlockComponents.Nonlinear.PadeDelay(n = 6, m = 5, delayTime = 0.3) {^delay}
  lag = BlockComponents.Continuous.FirstOrder(T = 0.3) {^lag}
  limiter = BlockComponents.Nonlinear.Limiter(y_max = 150, y_min = 0) {^limiter}
  torque = RotationalComponents.Sources.TorqueSource() {^torque}
relations
  connect(tau_cmd, delay.u) {^id1}
  connect(delay.y, lag.u) {^id2}
  connect(lag.y, limiter.u) {^id3}
  connect(limiter.y, torque.tau) {^id4}
  connect(torque.spline, spline) {^id5}
  connect(torque.support, support) {^id6}
end

"""A torque command above the ceiling, stepped in at 0.5 s, into a 1 kg·m² flywheel."""
component EngineStep
  cmd = BlockComponents.Sources.Step(height = 200, offset = 0, start_time = 0.5) {^cmd}
  engine = Engine() {^engine}
  "Unit inertia, so its angular acceleration reads as the delivered torque"
  load = RotationalComponents.Components.Inertia(J = 1) {^load}
  mounts = RotationalComponents.Components.Fixed() {^mounts}
relations
  connect(cmd.y, engine.tau_cmd) {^id1}
  connect(engine.spline, load.spline_a) {^id2}
  connect(engine.support, mounts.spline) {^id3}
  initial engine.lag.x = 0
  initial load.phi = 0
  initial load.w = 0
end

analysis EngineStepTransient
  extends TransientAnalysis(stop = 3)
  model = EngineStep()
end

Give the car its 1400 kg and the two forces that hold it back on a flat road: drag and rolling resistance.

Target diagram

Do this

  1. Create Body. Place the parts and wire the three forces — flange, drag.flange, rolling.flange — to mass.flange_a.
  2. Wire drag.support and rolling.support to ground.flange: drag and rolling resistance push against the road and the air, not against the car.
  3. Feed rolling its two signal inputs: cr_const.y → rolling.cr and incl_const.y → rolling.inclination. An unconnected input would leave the model incomplete.
  4. Set the drag parameters. f_nominal is negative, which makes the source a load; ForceDirection = false makes drag oppose motion both ways. -0.5 * 1.2 * 0.63 * 30 ^ 2 is ½ρ·CdA·v² at 30 m/s — type the expression, not the number.
Checkpoint

It saves without errors. Under a constant 500 N the reference test TestBody starts at 0.357 m/s² and settles at 29.78 m/s, where drag and rolling resistance add up to 500 N.

From dyad/HandsOn/Body.dyad, copied verbatim except that each metadata { … } block — diagram layout and test cases — is left out, and so is the test component. The {^…} tag at the end of a line points into that layout; the diagram editor writes it for you, and you can drop it if you type the code by hand. """
Car body on a flat road: tractive force in at the flange, resisted by aerodynamic drag and rolling
resistance.
"""
component Body
  "Tractive force from the driveline"
  flange = Flange() {^flange}
  mass = TranslationalComponents.Components.Mass(m = 1400) {^mass}
  # A negative nominal force makes the source a load; ForceDirection = false gives the v*|v| form,
  # so drag opposes motion in both directions.
  drag = TranslationalComponents.Sources.QuadraticSpeedDependentForce(ForceDirection = false, v_nominal = 30, f_nominal = -0.5 * 1.2 * 0.63 * 30 ^ 2) {^drag}
  rolling = TranslationalComponents.Components.RollingResistance(fWeight = 1400 * 9.80665) {^rolling}
  cr_const = BlockComponents.Sources.Constant(k = 0.012) {^cr_const}
  "Flat road: tan(alpha) = 0"
  incl_const = BlockComponents.Sources.Constant(k = 0) {^incl_const}
  ground = TranslationalComponents.Components.Fixed() {^ground}
relations
  connect(flange, mass.flange_a) {^id1}
  connect(drag.flange, mass.flange_a) {^id2}
  connect(rolling.flange, mass.flange_a) {^id3}
  connect(drag.support, ground.flange) {^id4}
  connect(rolling.support, ground.flange) {^id5}
  connect(cr_const.y, rolling.cr) {^id6}
  connect(incl_const.y, rolling.inclination) {^id7}
end

"""
Longitudinal car on a flat road: torque command in, speed in km/h out.
"""
component Car
  "Commanded engine torque"
  tau_cmd = RealInput() {^tau_cmd}
  "Vehicle speed in km/h"
  v_kmh = RealOutput() {^v_kmh}
  engine = Engine() {^engine}
  driveline = Driveline() {^driveline}
  body = Body() {^body}
  vsensor = TranslationalComponents.Sensors.VelocitySensor() {^vsensor}
  to_kmh = BlockComponents.Math.Gain(k = 3.6) {^to_kmh}
  "Engine mounts and gearbox housing"
  rot_ground = RotationalComponents.Components.Fixed() {^rot_ground}
  "Road under the wheel"
  trans_ground = TranslationalComponents.Components.Fixed() {^trans_ground}
relations
  connect(tau_cmd, engine.tau_cmd) {^id1}
  connect(engine.spline, driveline.spline) {^id2}
  connect(engine.support, rot_ground.spline) {^id3}
  connect(driveline.support_r, rot_ground.spline) {^id4}
  connect(driveline.flange, body.flange) {^id5}
  connect(driveline.support_t, trans_ground.flange) {^id6}
  connect(vsensor.flange, body.flange) {^id7}
  connect(vsensor.v, to_kmh.u) {^id8}
  connect(to_kmh.y, v_kmh) {^id9}
end

  # continuously differentiable across the segment joins.
