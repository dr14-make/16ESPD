Engine

Say: this is the engine from the lecture: a transport delay, a first-order lag, a ceiling. The delay and the lag are what made Ziegler–Nichols and Cohen–Coon possible in notebook 08 — without them the car is first order and never oscillates.

Timing: 20 minutes, the longest in-class step. It is the first bench, the first analysis and the first plot; everything after reuses the pattern.

Finish the chain, then build a bench

Parameters theta_e = 0.3 (structural), tau_e = 0.3, T_max = 150 — the parts use the names.

tau_cmd → delay → lag → limiter (y_max = T_max, y_min = 0) → torque → spline; torque.support → support.

Bench EngineStep: a Step of 200 N·m at 0.5 s into your Engine, a 1 kg·m² Inertia on the shaft, the mounts Fixed.

Say — name each value once: a number a part needs becomes a parameter of the component, added with Add parameter in the component panel, and the part refers to it by name. Engine(T_max = 200) then changes the ceiling in one place. theta_e is structural because PadeDelay builds its coefficients when the model compiles; if the panel offers no structural option, paste the line in code.

Say: 200 is above the ceiling on purpose. The plot should show the limiter doing its job.

They get wrong: leaving support unconnected in the bench. A torque source needs something to push against — the engine mounts. The compile error talks about an unbalanced system; the fix is the Fixed.

Why y_min = 0: the engine cannot brake through this path. Ask the room what would happen at a negative command without it.

The analysis is code

EngineStep — complete bench and analysis
component EngineStep
  cmd = BlockComponents.Sources.Step(height = 200, offset = 0, start_time = 0.5)
  engine = Engine()
  "Unit inertia, so its angular acceleration reads as the delivered torque"
  load = RotationalComponents.Components.Inertia(J = 1)
  mounts = RotationalComponents.Components.Fixed()
relations
  connect(cmd.y, engine.tau_cmd)
  connect(engine.spline, load.spline_a)
  connect(engine.support, mounts.spline)
  initial engine.lag.x = 0
  initial load.phi = 0
  initial load.w = 0
end

analysis EngineStepTransient
  extends TransientAnalysis(stop = 3)
  model = EngineStep()
end

Save → EngineStepTransient appears in Analyses → ▷.

Say: two things have no diagram form. The starting state — where every state variable begins — and the analysis, which is an instruction, not a part.

Plot one signal, not all of them

Julia REPL
using MyCar, Plots
r = MyCar.EngineStepTransient()
plot(r; idxs = r."engine.limiter.y")
0until 0.5 s + dead time
97.5N·m at 1.0 s
150N·m from 1.22 s

Say: the default plot draws every state. The delay has six internal states that swing into the thousands, and they bury the one curve you care about. Pick it by name with idxs.

Point at: the flat start. The command arrived at 0.5 s; torque starts at about 0.8 s. That 0.3 s is the transport delay. The small wiggles before it are the Padé approximation of a delay, not physics.
