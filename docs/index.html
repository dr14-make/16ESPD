Lecture 1

Control Systems: Introduction and PID

One car, three fidelity levels, ten notebooks. Open loop and closed loop, P, PI and PID, integral windup, the step test and heuristic tuning, discretization, and what happens to cruise control on ice.

For the lecturer

Two screens

Deck on the projector, Jupyter on the laptop. Press S in the deck for the speaker view — notes, timer and next slide. If the browser blocks the popup, press C for the same notes as a panel in the deck window.

Every demo slide is executable

Each one names the notebook file and the cell heading, carries the code, and has a copy button.

Handout

Append ?print-pdf to the deck URL and print to PDF. One slide per page, speaker notes excluded.

No network needed

reveal.js and KaTeX are vendored into slides/lecture-01/assets/. The deck opens from file:// with the wifi off — which is how it should be checked before the lecture.
